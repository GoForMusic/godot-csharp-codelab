3D Nodes & Scripts

Attach C# scripts to 3D nodes, understand the core math types — Vector3, Transform3D, Basis, Quaternion — and write your first rotating object.

Your First 3D Script

C# MyObject.cs 
using Godot;

public partial class MyObject : Node3D
{
    [Export] public float RotationSpeed = 2.0f;
    [Export] public Vector3 StartPosition = Vector3.Zero;

    private float _time = 0f;

    public override void _Ready()
    {
        GlobalPosition = StartPosition;
        GD.Print("MyObject ready at: ", GlobalPosition);
    }

    public override void _Process(double delta)
    {
        _time += (float)delta;
        RotateY(RotationSpeed * (float)delta);
        Position = StartPosition + new Vector3(
            0f,
            Mathf.Sin(_time * 2f) * 0.3f,
            0f
        );
    }
}

Essential 3D Types

📐
Vector3
Three-component float vector for position, direction, scale, and velocity. Key constants: Vector3.Zero, Vector3.Up, Vector3.Forward (0,0,-1).
🔄
Transform3D
Combines a Basis (rotation+scale) and Origin (position). Every Node3D has Transform (local) and GlobalTransform.
🧭
Basis
3x3 matrix for orientation and scale. Columns are local X, Y, Z axes. Use basis.GetEuler() or convert to/from Quaternion.
🔃
Quaternion
Four-component rotation — no gimbal lock. Use Quaternion.FromEuler() and Slerp() for smooth rotational interpolation.

Getting Nodes in C#

C# NodeAccess.cs 
public partial class NodeAccess : Node3D
{
    private MeshInstance3D     _mesh;
    private CollisionShape3D   _col;
    private AudioStreamPlayer3D _audio;

    public override void _Ready()
    {
        // By node name
        _mesh  = GetNode<MeshInstance3D>("MeshInstance3D");

        // Null-safe (returns null if not found)
        _col   = GetNodeOrNull<CollisionShape3D>("CollisionShape3D");

        // Unique name (set % in scene, faster lookup)
        _audio = GetNode<AudioStreamPlayer3D>("%AudioPlayer");

        // Autoload singleton from project settings
        var gm = GetNode<GameManager>("/root/GameManager");
    }
}
✅
Always cache in _Ready() — calling GetNode() every frame in _Process() is expensive. Store references in private fields and reuse them.

Full Player Controller

C# Player.cs 
using Godot;

public partial class Player : CharacterBody3D
{
    [Export] public float Speed        = 5f;
    [Export] public float JumpVelocity = 7f;
    [Export] public float Acceleration = 12f;
    [Export] public float Friction     = 10f;

    private const float Gravity = 9.8f * 2.5f; // stronger for snappy feel

    private Node3D _yawPivot;   // camera horizontal rotation
    private Node3D _pitchPivot; // camera vertical rotation

    public override void _Ready()
    {
        _yawPivot   = GetNode<Node3D>("YawPivot");
        _pitchPivot = GetNode<Node3D>("YawPivot/PitchPivot");
        Input.MouseMode = Input.MouseModeEnum.Captured;
    }

    public override void _PhysicsProcess(double delta)
    {
        var vel = Velocity;

        // --- Gravity ---
        if (!IsOnFloor())
            vel.Y -= Gravity * (float)delta;

        // --- Jump ---
        if (Input.IsActionJustPressed("jump") && IsOnFloor())
            vel.Y = JumpVelocity;

        // --- Input direction (relative to camera yaw) ---
        Vector2 input = Input.GetVector(
            "move_left", "move_right",
            "move_forward", "move_back"
        );

        // Transform input by camera yaw so WASD follows camera facing
        Vector3 dir = (_yawPivot.GlobalTransform.Basis *
                        new Vector3(input.X, 0f, input.Y)).Normalized();

        // --- Horizontal velocity with acceleration/friction ---
        if (dir != Vector3.Zero)
        {
            vel.X = Mathf.MoveToward(vel.X, dir.X * Speed, Acceleration * (float)delta);
            vel.Z = Mathf.MoveToward(vel.Z, dir.Z * Speed, Acceleration * (float)delta);
        }
        else
        {
            // Decelerate to zero when no input
            vel.X = Mathf.MoveToward(vel.X, 0f, Friction * (float)delta);
            vel.Z = Mathf.MoveToward(vel.Z, 0f, Friction * (float)delta);
        }

        Velocity = vel;
        MoveAndSlide(); // handles collision, slopes, stairs
    }
}
💡
Camera Basis Trick — multiplying the input vector by _yawPivot.GlobalTransform.Basis converts it from camera-local space to world space. This makes WASD always move relative to where the camera is facing, regardless of rotation.

Camera & Mouse Input

Implement a full mouse-look camera with yaw/pitch pivots, mouse capture/release, and optional SpringArm3D for smooth collision-avoiding third-person view.

Camera Controller

C# CameraController.cs 
using Godot;

/// Attach to the YawPivot Node3D. PitchPivot is a child of YawPivot.
public partial class CameraController : Node3D
{
    [Export] public float Sensitivity = 0.003f;
    [Export] public float PitchMin    = -80f;
    [Export] public float PitchMax    =  80f;

    private Node3D _pitchPivot;
    private float  _yaw   = 0f;
    private float  _pitch = 0f;

    public override void _Ready()
    {
        _pitchPivot = GetNode<Node3D>("PitchPivot");
        Input.MouseMode = Input.MouseModeEnum.Captured;
    }

    public override void _Input(InputEvent e)
    {
        // Release cursor on Escape
        if (e.IsActionPressed("ui_cancel"))
        {
            Input.MouseMode = Input.MouseModeEnum.Visible;
        }

        // Re-capture on click
        if (e is InputEventMouseButton mb)
        {
            if (mb.Pressed)
                Input.MouseMode = Input.MouseModeEnum.Captured;
        }

        // Mouse look
        if (e is InputEventMouseMotion mm &&
            Input.MouseMode == Input.MouseModeEnum.Captured)
        {
            // Yaw: rotate the whole pivot horizontally
            _yaw -= mm.Relative.X * Sensitivity;
            RotationDegrees = new Vector3(0f, Mathf.RadToDeg(_yaw), 0f);

            // Pitch: rotate only PitchPivot, clamped
            _pitch -= mm.Relative.Y * Sensitivity;
            _pitch  = Mathf.Clamp(
                _pitch,
                Mathf.DegToRad(PitchMin),
                Mathf.DegToRad(PitchMax)
            );
            _pitchPivot.RotationDegrees = new Vector3(
                Mathf.RadToDeg(_pitch), 0f, 0f
            );
        }
    }
}

SpringArm3D for Third-Person

C# SpringArmSetup.cs (partial) 
// Add SpringArm3D as child of PitchPivot
// Camera3D is child of SpringArm3D (at local Z = 0)
private SpringArm3D _arm;
private const float ArmMin = 1f;
private const float ArmMax = 6f;

public override void _Ready()
{
    _arm = GetNode<SpringArm3D>("PitchPivot/SpringArm3D");
    _arm.SpringLength = 3f;
}

public override void _Input(InputEvent e)
{
    if (e is InputEventMouseButton mb && mb.Pressed)
    {
        if (mb.ButtonIndex == MouseButton.WheelUp)
            _arm.SpringLength = Mathf.Clamp(_arm.SpringLength - 0.5f, ArmMin, ArmMax);
        if (mb.ButtonIndex == MouseButton.WheelDown)
            _arm.SpringLength = Mathf.Clamp(_arm.SpringLength + 0.5f, ArmMin, ArmMax);
    }
}
📌
SpringArm3D automatically shortens its length when a wall is between the player and camera, preventing the camera from clipping through geometry. Set its collision mask to match your wall/floor layers.

AnimationPlayer for Doors

C# Door.cs 
using Godot;

public partial class Door : Node3D
{
    [Export] public bool StartOpen = false;

    private AnimationPlayer _anim;
    private bool _isOpen = false;

    public override void _Ready()
    {
        _anim = GetNode<AnimationPlayer>("AnimationPlayer");
        _anim.AnimationFinished += OnAnimationFinished;

        if (StartOpen) Open();
    }

    public void Open()
    {
        if (_isOpen) return;
        _isOpen = true;
        _anim.Play("door_open");
    }

    public void Close()
    {
        if (!_isOpen) return;
        _isOpen = false;
        _anim.PlayBackwards("door_open"); // reuse animation reversed
    }

    private void OnAnimationFinished(StringName animName)
    {
        GD.Print($"Door animation '{animName}' finished.");
    }
}

AnimationTree State Machine in C#

C# Player.cs (animation portion) 
private AnimationTree    _animTree;
private AnimationNodeStateMachinePlayback _sm;

public override void _Ready()
{
    _animTree = GetNode<AnimationTree>("AnimationTree");
    _animTree.Active = true;

    // Get the state machine playback controller
    _sm = (AnimationNodeStateMachinePlayback)
          _animTree.Get("parameters/playback");
}

private void UpdateAnimations(Vector3 velocity)
{
    float speed = new Vector2(velocity.X, velocity.Z).Length();

    // Pass blend amounts for directional movement blending
    _animTree.Set("parameters/Walk/blend_position", speed / Speed);

    // Transition between states using Travel()
    if (!IsOnFloor())
    {
        if (Velocity.Y > 0.1f)
            _sm.Travel("Jump");
        else
            _sm.Travel("Fall");
    }
    else if (speed > 4f)
        _sm.Travel("Run");
    else if (speed > 0.1f)
        _sm.Travel("Walk");
    else
        _sm.Travel("Idle");
}

Animation Scene Tree

Player (CharacterBody3D)
├── Armature (Node3D)
└── Skeleton3D
└── MeshInstance3D (skinned mesh)
├── AnimationPlayer ← holds raw clips
└── AnimationTree ← state machine logic
💡
Travel() vs Play() — Travel() follows the transition conditions defined in the AnimationTree state machine (respecting blend times and conditions). Play() on AnimationPlayer jumps directly with no blending. Always prefer Travel() for character animations.

Sound & Music System

Build a centralized AudioManager autoload that pools SFX players, streams background music, and handles 3D positional audio for immersive environments.

Audio Node Types

🔊
AudioStreamPlayer
Non-positional audio. Perfect for UI sounds, background music, and global game events. Uses the Master bus by default.
📡
AudioStreamPlayer3D
3D positional audio. Attenuates by distance, supports Doppler effect. Place it in the world where the sound originates.
🎵
AudioStreamPlayer2D
2D positional audio. Useful in hybrid 2D/3D games for UI planes or minimaps with spatial audio feedback.

AudioManager Autoload Singleton

C# AudioManager.cs (autoload) 
using Godot;
using System.Collections.Generic;

public partial class AudioManager : Node
{
    private const int PoolSize = 8;

    private AudioStreamPlayer   _musicPlayer;
    private List<AudioStreamPlayer> _sfxPool = new();
    private int _poolIndex = 0;

    public override void _Ready()
    {
        // Create music player
        _musicPlayer = new AudioStreamPlayer { Bus = "Music" };
        AddChild(_musicPlayer);

        // Create SFX pool for non-positional sounds
        for (int i = 0; i < PoolSize; i++)
        {
            var p = new AudioStreamPlayer { Bus = "SFX" };
            AddChild(p);
            _sfxPool.Add(p);
        }
    }

    /// Play a non-positional sound effect with optional pitch variance
    public void PlaySFX(AudioStream stream, float pitchVariance = 0f)
    {
        var player = _sfxPool[_poolIndex];
        player.Stream = stream;
        player.PitchScale = 1f + (float)GD.RandRange(-pitchVariance, pitchVariance);
        player.Play();

        _poolIndex = (_poolIndex + 1) % PoolSize; // round-robin
    }

    /// Crossfade to new music track
    public void PlayMusic(AudioStream track, float volume = 0f)
    {
        if (_musicPlayer.Stream == track) return;
        _musicPlayer.Stream = track;
        _musicPlayer.VolumeDb = volume;
        _musicPlayer.Play();
    }

    public void StopMusic() => _musicPlayer.Stop();

    /// Retrieve AudioManager from anywhere
    public static AudioManager Instance(Node node) =>
        node.GetNode<AudioManager>("/root/AudioManager");
}

3D Positional Sound (Explosion)

C# Explosion.cs 
using Godot;

public partial class Explosion : Node3D
{
    [Export] public AudioStream ExplosionSFX;
    [Export] public float MaxDistance = 40f;
    [Export] public float PitchVariance = 0.15f;

    private AudioStreamPlayer3D _audio;

    public override void _Ready()
    {
        _audio = new AudioStreamPlayer3D
        {
            Stream         = ExplosionSFX,
            MaxDistance    = MaxDistance,
            AttenuationModel = AudioStreamPlayer3D.AttenuationModelEnum.InverseSquare,
            UnitSize       = 5f,
            Bus            = "SFX",
            PitchScale     = 1f + (float)GD.RandRange(-PitchVariance, PitchVariance)
        };
        AddChild(_audio);
        _audio.Play();
        // Auto-remove when done
        _audio.Finished += () => QueueFree();
    }
}
🎶
Pitch Variance — playing the same sound with slight random pitch variation (PitchScale ± 0.1–0.2) prevents repetitive audio fatigue, especially for impact sounds, footsteps, and ambient effects. This is standard in commercial games.

C# HUD.cs 
using Godot;

public partial class HUD : CanvasLayer
{
    private TextureProgressBar _healthBar;
    private Label              _ammoLabel;
    private Label              _scoreLabel;
    private Control            _pauseMenu;
    private int                _score = 0;

    public override void _Ready()
    {
        _healthBar  = GetNode<TextureProgressBar>("%HealthBar");
        _ammoLabel  = GetNode<Label>("%AmmoLabel");
        _scoreLabel = GetNode<Label>("%ScoreLabel");
        _pauseMenu  = GetNode<Control>("%PauseMenu");

        // Ensure HUD updates even when the game is paused
        ProcessMode = ProcessModeEnum.Always;
        _pauseMenu.Visible = false;
    }

    public override void _Process(double delta)
    {
        if (Input.IsActionJustPressed("ui_cancel"))
            TogglePause();
    }

    public void SetHealth(float current, float max)
    {
        _healthBar.MaxValue = max;
        _healthBar.Value    = current;
    }

    public void SetAmmo(int current, int total)
    {
        _ammoLabel.Text = $"{current} / {total}";
    }

    public void AddScore(int points)
    {
        _score += points;
        _scoreLabel.Text = $"Score: {_score:N0}";
    }

    private void TogglePause()
    {
        bool paused = !GetTree().Paused;
        GetTree().Paused     = paused;
        _pauseMenu.Visible  = paused;
        Input.MouseMode = paused
            ? Input.MouseModeEnum.Visible
            : Input.MouseModeEnum.Captured;
    }
}
⚠️
ProcessMode = Always — by default nodes stop processing when the scene tree is paused. Setting ProcessMode = ProcessModeEnum.Always ensures the HUD (especially pause menus and health bars) continues updating even while gameplay is frozen.

Signals & Events

Decouple game systems using Godot signals and a global EventBus autoload. Learn to declare custom signals, subscribe from other nodes, and avoid memory leaks.

Custom Signals in C#

C# Player.cs (signals) 
using Godot;

public partial class Player : CharacterBody3D
{
    // Declare signals with [Signal] attribute
    [Signal] public delegate void HealthChangedEventHandler(float current, float max);
    [Signal] public delegate void DiedEventHandler();
    [Signal] public delegate void ItemPickedUpEventHandler(StringName itemId);

    private float _health    = 100f;
    private float _maxHealth = 100f;

    public void TakeDamage(float amount)
    {
        _health = Mathf.Max(0f, _health - amount);

        // Emit signal — any subscriber is notified
        EmitSignal(SignalName.HealthChanged, _health, _maxHealth);

        if (_health == 0f)
            EmitSignal(SignalName.Died);
    }
}

// --- GameManager subscribes to Player signals ---
public partial class GameManager : Node
{
    private Player _player;

    public override void _Ready()
    {
        _player = GetNode<Player>("%Player");

        // Connect signal to local method
        _player.HealthChanged += OnHealthChanged;
        _player.Died          += OnPlayerDied;
    }

    public override void _ExitTree()
    {
        // Always disconnect when leaving the tree to prevent leaks
        if (IsInstanceValid(_player))
        {
            _player.HealthChanged -= OnHealthChanged;
            _player.Died          -= OnPlayerDied;
        }
    }

    private void OnHealthChanged(float current, float max)
    {
        GetNode<HUD>("%HUD").SetHealth(current, max);
    }

    private void OnPlayerDied() => ShowGameOver();
}

using Godot;

public partial class Enemy : CharacterBody3D
{
    public enum State { Idle, Patrol, Chase, Attack, Dead }

    [Export] public float MoveSpeed    = 3.5f;
    [Export] public float ChaseRange   = 15f;
    [Export] public float AttackRange  = 2f;
    [Export] public float AttackDamage = 15f;
    [Export] public float MaxHealth    = 80f;

    private State              _state  = State.Idle;
    private float              _hp;
    private NavigationAgent3D  _nav;
    private Node3D             _player;
    private float              _attackCooldown = 0f;
    private const float        AttackRate      = 1.5f;
    private const float        Gravity         = 9.8f * 2f;

    public override void _Ready()
    {
        _hp     = MaxHealth;
        _nav    = GetNode<NavigationAgent3D>("NavigationAgent3D");
        _player = GetNode<Node3D>("/root/World/Player");

        _nav.PathDesiredDistance  = 0.5f;
        _nav.TargetDesiredDistance = 1.0f;
    }

    public override void _PhysicsProcess(double delta)
    {
        float dt   = (float)delta;
        float dist = GlobalPosition.DistanceTo(_player.GlobalPosition);

        // Apply gravity
        var vel = Velocity;
        if (!IsOnFloor()) vel.Y -= Gravity * dt;

        _attackCooldown -= dt;

        switch (_state)
        {
            case State.Idle:
                if (dist < ChaseRange) SetState(State.Chase);
                break;

            case State.Chase:
                _nav.TargetPosition = _player.GlobalPosition;
                if (!_nav.IsNavigationFinished())
                {
                    Vector3 next = _nav.GetNextPathPosition();
                    Vector3 dir  = (next - GlobalPosition).Normalized();
                    vel.X = dir.X * MoveSpeed;
                    vel.Z = dir.Z * MoveSpeed;
                    LookAt(_player.GlobalPosition * new Vector3(1,0,1) + new Vector3(0,GlobalPosition.Y,0), Vector3.Up);
                }
                if (dist < AttackRange) SetState(State.Attack);
                if (dist > ChaseRange * 1.5f) SetState(State.Idle);
                break;

            case State.Attack:
                vel.X = 0f; vel.Z = 0f;
                if (_attackCooldown <= 0f)
                {
                    _attackCooldown = AttackRate;
                    (_player as Player)?.TakeDamage(AttackDamage);
                }
                if (dist > AttackRange * 1.5f) SetState(State.Chase);
                break;
        }

        Velocity = vel;
        if (_state != State.Dead) MoveAndSlide();
    }

    public void TakeDamage(float amount)
    {
        if (_state == State.Dead) return;
        _hp -= amount;
        if (_hp <= 0f) SetState(State.Dead);
        else if (_state == State.Idle) SetState(State.Chase);
    }

    private void SetState(State next)
    {
        _state = next;
        if (next == State.Dead)
        {
            // Play death anim and queue free after delay
            GetTree().CreateTimer(2.0f).Timeout += QueueFree;
        }
    }
}

public partial class SaveManager : Node
{
    private const string SavePath = "user://savegame.json";

    private static readonly JsonSerializerOptions JsonOpts = new()
    {
        WriteIndented = true,
        DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull
    };

    public void Save(SaveData data)
    {
        string json = JsonSerializer.Serialize(data, JsonOpts);

        // user:// resolves to the OS-appropriate writable directory
        using var file = FileAccess.Open(SavePath, FileAccess.ModeFlags.Write);
        file.StoreString(json);
        GD.Print("Game saved to: ", ProjectSettings.GlobalizePath(SavePath));
    }

    public SaveData Load()
    {
        if (!FileAccess.FileExists(SavePath))
        {
            GD.Print("No save file found, returning defaults.");
            return new SaveData();
        }

        using var file = FileAccess.Open(SavePath, FileAccess.ModeFlags.Read);
        string json = file.GetAsText();
        return JsonSerializer.Deserialize<SaveData>(json) ?? new SaveData();
    }

    public void Delete()
    {
        if (FileAccess.FileExists(SavePath))
            DirAccess.RemoveAbsolute(ProjectSettings.GlobalizePath(SavePath));
    }

    public static SaveManager Get(Node n) =>
        n.GetNode<SaveManager>("/root/SaveManager");
}

Scene Management

Load scenes asynchronously in the background with ResourceLoader so your game never freezes during transitions, complete with a progress bar HUD.

Async Scene Loading with Progress

C# SceneManager.cs (autoload) 
using Godot;
using System.Collections.Generic;

public partial class SceneManager : CanvasLayer
{
    [Signal] public delegate void SceneLoadedEventHandler();

    private ProgressBar _bar;
    private Control     _overlay;
    private string      _pending   = "";
    private bool        _loading   = false;

    public override void _Ready()
    {
        Layer    = 100; // render above everything
        _bar     = GetNode<ProgressBar>("%LoadBar");
        _overlay = GetNode<Control>("%Overlay");
        _overlay.Visible = false;
    }

    /// Begin background loading of a scene path
    public void GoTo(string scenePath)
    {
        if (_loading) return;
        _pending = scenePath;
        _loading = true;

        _overlay.Visible = true;
        _bar.Value = 0;

        // Non-blocking background load request
        ResourceLoader.LoadThreadedRequest(scenePath);
    }

    public override void _Process(double delta)
    {
        if (!_loading) return;

        var progress = new Godot.Collections.Array();
        var status = ResourceLoader.LoadThreadedGetStatus(_pending, progress);

        if (progress.Count > 0)
            _bar.Value = (float)progress[0] * 100f;

        if (status == ResourceLoader.ThreadLoadStatus.Loaded)
        {
            var scene = (PackedScene)ResourceLoader.LoadThreadedGet(_pending);
            _loading = false;
            _overlay.Visible = false;
            GetTree().ChangeSceneToPacked(scene);
            EmitSignal(SignalName.SceneLoaded);
        }
    }

    public static SceneManager Get(Node n) =>
        n.GetNode<SceneManager>("/root/SceneManager");
}

Particle System Diagram

GPUParticles3D Emission Pattern

GPUParticles3D Properties

💥
Amount & Lifetime
Amount is total particles in the pool. Lifetime is how long each particle lives in seconds. Higher amount = denser effect but more GPU cost.
🌀
Emission Shape
Point, Sphere, Box, Ring, or Mesh surface. Set via the ParticleProcessMaterial.EmissionShape property to control spawn area.
🧪
Process Material
ParticleProcessMaterial (for GPU particles) controls velocity, gravity, color ramp, scale curve, and turbulence. All GPU-computed.
⏱️
One Shot / Burst
Enable OneShot for burst effects (explosion, impact). Leave off for looping effects (fire, rain). Use Emitting = true to trigger from code.

Glow / Emission Shader

GDShader glow_emission.gdshader 
shader_type spatial;
render_mode unshaded;

// Uniforms are set from C# via ShaderMaterial.SetShaderParameter()
uniform vec4  emission_color : source_color = vec4(0.0, 0.9, 0.75, 1.0);
uniform float pulse_speed    = 2.0;
uniform float pulse_amount   = 0.3;
uniform float base_emission  = 1.5;

void fragment() {
    // Pulse brightness using a sine wave on TIME
    float pulse = 1.0 + sin(TIME * pulse_speed) * pulse_amount;
    EMISSION = emission_color.rgb * (base_emission * pulse);
    ALBEDO   = emission_color.rgb * 0.1; // slight base color
    ALPHA    = emission_color.a;
}

Outline / Rim Shader

GDShader outline_rim.gdshader 
shader_type spatial;
render_mode cull_front, unshaded;

uniform vec4  outline_color : source_color = vec4(1.0, 0.4, 0.0, 1.0);
uniform float outline_width = 0.03;

void vertex() {
    // Push vertices along their normal to create the outline shell
    vec4 pos    = PROJECTION_MATRIX * MODELVIEW_MATRIX * vec4(VERTEX, 1.0);
    vec4 normal = PROJECTION_MATRIX * MODELVIEW_MATRIX * vec4(NORMAL, 0.0);
    vec2 offset = normalize(normal.xy) * outline_width * pos.w;
    POSITION = pos + vec4(offset, 0.0, 0.0);
}

void fragment() {
    ALBEDO = outline_color.rgb;
}

Multiplayer

Build authoritative client-server multiplayer using ENet, the [Rpc] attribute for remote procedure calls, and MultiplayerSynchronizer for automatic state sync.

Network Topology Diagram

Server-Client Architecture

Multiplayer Concepts

👑
Authority
Each node has one authority peer (default: server = peer 1). Only the authority should write state. Check with IsMultiplayerAuthority().
📡
RPC
Remote Procedure Call — invoke a method on a remote peer. Mark methods with [Rpc] attribute. Call via Rpc(), RpcId(), or RpcOnServer().
🆔
Peer ID
Each connected peer gets a unique integer ID. Server always has ID 1. Get own ID with Multiplayer.GetUniqueId().
🔄
Synchronizer
MultiplayerSynchronizer automatically replicates node properties from authority to all peers each physics tick. Handles interpolation.

Server & Client Setup

C# NetworkManager.cs 
using Godot;

public partial class NetworkManager : Node
{
    private const int Port    = 7777;
    private const int MaxPeers = 8;

    /// Start as dedicated server
    public void StartServer()
    {
        var peer = new ENetMultiplayerPeer();
        peer.CreateServer(Port, MaxPeers);
        Multiplayer.MultiplayerPeer = peer;

        Multiplayer.PeerConnected    += OnPeerConnected;
        Multiplayer.PeerDisconnected += OnPeerDisconnected;

        GD.Print($"Server listening on port {Port}");
    }

    /// Connect as client to a server IP
    public void JoinServer(string ip)
    {
        var peer = new ENetMultiplayerPeer();
        peer.CreateClient(ip, Port);
        Multiplayer.MultiplayerPeer = peer;

        Multiplayer.ConnectedToServer += () =>
            GD.Print($"Connected! My peer ID: {Multiplayer.GetUniqueId()}");
    }

    private void OnPeerConnected(long id)
    {
        GD.Print($"Peer {id} joined");
        // Spawn player for this peer
        if (Multiplayer.IsServer())
            RpcId(id, MethodName.SpawnPlayer, id);
    }

    private void OnPeerDisconnected(long id) =>
        GD.Print($"Peer {id} left");

    [Rpc(MultiplayerApi.RpcMode.AnyPeer, CallLocal = true)]
    private void SpawnPlayer(long peerId)
    {
        // Called on all clients to instantiate the new player
        GD.Print($"Spawning player for peer {peerId}");
    }
}
